# Feature Overview

## Connection Profiles
Create, edit, and organize RDP connections with custom settings.

## Credential Management
Securely store credentials using Windows DPAPI or connect without saving passwords.

## Server Groups
Organize servers into logical folders for fast access.

## Advanced RDP Settings
Configure resolution, color depth, performance flags, and gateway options.

## UI Enhancements
- Clean WPF interface  
- Search and filtering  
- Status indicators  
- Resizable tiles
